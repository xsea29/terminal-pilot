# Changelog

## 1.1.1

- Added the extension icon.

## 1.1.0

### Added
- **Reorder startup commands.** Drag a command by its grip (⋮⋮) in the form, or use the arrow keys on the grip (Alt+Up / Alt+Down inside the text box). The saved order is the order the commands run in, including after you edit an existing terminal.
- **Blank commands are refused.** Clicking *Add command* (or pressing Enter) on an empty box, or saving with an empty box between other commands, outlines that box in red instead of adding it. The red clears as soon as you type.

### Improved
- **Delete toast.** The "Deleted …" message now has a status icon, a clear **Undo** button, a dismiss button and a countdown bar showing how long Undo stays available.
- An invalid field now shows a single red outline, even while it has focus.

## 1.0.0

- Initial release: create, edit, duplicate, delete, run and stop dedicated terminals from a panel; global and workspace scope; terminal dropdown profiles; Windows, Linux and macOS support.
